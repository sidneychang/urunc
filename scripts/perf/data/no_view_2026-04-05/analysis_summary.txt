对比观察（峰值）:
- 可用内存随 N 下降：blockfile 与 devmapper 趋势相近，N=50 时 blockfile 可用内存略低若干 GB（见曲线图）。
- devmapper：snapshotter 插件目录 du（snapshotter_root）几乎不变；真实数据在 thin pool（thin_data_used / 百分比随 N 升）。
- blockfile：snapshotter_root 随 N 近似线性增长（每容器一块稀疏文件等），与 README 描述一致。
- /run/containerd（run_containerd_bytes）在两种后端下随 N 同步增长，反映 bundle/monRootfs 等运行时文件。
